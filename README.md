# Human Reconstruction Paper Collection

A public-source scholarly archive of human 3D reconstruction, body pose/shape, clothed geometry, neural and Gaussian avatars, and video/4D humans. Face, hand and hair are labeled related topics.

Open [the live collection](https://minotrey.github.io/Human-Reconstruction-Paper-Collection/).

The default reference layer contains 1,929 records. The optional 14,423-record candidate layer includes uncertain and out-of-scope search hits. Bibliographic evidence is separate from technical-method review.

Static files need no dependencies. Preview with `python -m http.server 4182 --bind 127.0.0.1`. GitHub Pages serves the main branch root. `data/reference.json` and `data/candidates.json` are compact metadata indexes. Detail shards load only on demand. All charts aggregate the current filtered records using the same selected year basis.

Update records in the JSON indexes and corresponding detail shard. Preserve exact titles, source links and evidence labels. Do not infer a venue from an arXiv year or a method lineage from citations. Review 2026 as a partial year through October 20.

Public metadata only. No private research, credentials, PDFs or per-paper PNG cards are included. See [source and aggregation rules](about.html).

Editorial field corrections and old-ID aliases: `downloads/editorial-reviews.json`. Original frozen corpus retained locally; one ECON alias removed from active web counts. Reading relationships distinguish extensions, body-model dependencies, alternatives and experimental baselines. Unknown comparison fields stay unknown. No performance ranking is inferred.
