자료와 날짜 기준

인체 복원 논문을 찾아 읽기 위한 공개 자료 아카이브입니다. 기본 목록은 1,933편이며, 범위를 넓혀 보는 검색 자료 전체 14,424편에는 주제와 맞지 않는 검색 결과도 포함됩니다.

목록에 포함하는 연구

전신 또는 머리·얼굴·손 등 인체 부분의 3D 형상·자세·아바타·동적 복원과, 이를 직접 지원하는 몸 모델·데이터·평가를 포함합니다. 수집 경로와 무관하게 연구 내용을 기준으로 조금씩 적용합니다. 행동인식만을 위한 자료 압축처럼 복원과 직접 연결되지 않는 연구는 기본 목록 밖에 두고 원래 검색 자료에는 보존합니다.

앞선 소규모 검토에서는 10편을 대상으로 8편 포함·1편 제외·1편 확장판 연결를 판정했습니다. 실제 기본 목록 변경은 GPAvatar(2024) 편입과 ProMoDD 제외입니다. HHAvatar는 Gaussian Head Avatar의 확장판으로 연결하며 독립 논문 수를 늘리지 않습니다. 나머지 기존 문헌 전체를 검토 완료했다는 뜻은 아닙니다. 이번 범위 판단과 원문 근거

이후 고카메라동작 세계 좌표 인체 복원 연구 1편을 원문 근거로 기본 목록에 추가했습니다. 기존 후보 기록과 ID는 보존합니다. 부위는 전신으로 분류하며, 전체 후보의 관련성·최초 발표일을 전수 검증했다는 뜻은 아닙니다.

RealMe(2026-10-21 공개)를 한 편 새로 수록했습니다. 원래 10월 20일 후보 14,423건은 보존하며 현재 전체 검색은 이 한 편을 더한 14,424건입니다. 전체 수집을 10월 23일까지 갱신했다는 뜻은 아니며, 고정 분석 표본·수치는 변경하지 않았습니다.

머리·목·어깨의 스캔 기반 형상 모델 HNS 연구도 기존 후보 ID를 유지해 기본 목록에 포함했습니다. 부위는 얼굴·머리이며, 기존 수집 자료나 고정 통계의 모집틀을 바꾸지 않았습니다.

Microsoft DAViD는 인체 복원에 쓸 깊이·노멀·전경 단서 모델로 기본 목록에 포함했습니다. 완성 메시나 매개변수 몸 모델과 구분하며, 같은 이름의 로봇 DAViD는 별개 기록으로 보존합니다.

날짜와 정렬

첫 공개일 (arXiv v1)은 원고를 처음 제출한 날짜입니다. 학회·저널 발행일은 출판된 버전의 날짜이며, 두 날짜를 섞지 않습니다. 수정일은 상세 정보에서 따로 볼 수 있습니다.

날짜순에서는 먼저 연도를 비교하고, 같은 해 안에서는 날짜를 아는 자료를 정렬한 뒤 월만 아는 자료, 연도만 아는 자료를 둡니다. 모르는 월·일을 1월 1일로 채우지 않습니다. 날짜가 같을 때만 제목순을 사용합니다. 검색 관련도순은 제목·별칭을 먼저 찾고, 최신·오래된 날짜순을 직접 고르면 검색 관련도가 날짜 순서를 바꾸지 않습니다.

그래프는 현재 검색·필터와 같은 문헌을 셉니다. 날짜 기준도 같습니다. 2026년은 부분 연도입니다. 10월 20일 수집분에 RealMe(10월 21일 공개) 한 편만 추가했습니다. 이 수집 목록만으로 분야 전체의 성장·감소를 단정할 수 없습니다.

논문과 공개 자료

Paper는 논문, Project는 저자 프로젝트, GitHub는 코드입니다. Hugging Face는 HF Model, HF Dataset, HF Demo로 나눕니다. 없는 링크를 추측해 채우지 않으며, 같은 논문의 arXiv 요약·PDF 주소를 여러 주요 버튼으로 나열하지 않습니다. 학회 버전과 arXiv 원고가 있으면 논문 정보에서 다른 버전으로 안내합니다.

연구 흐름 분석

2019–2025 색인 연도의 초록 확보·식별 보류 제외 모집틀 1,099편에서 연도·출처 층화로 뽑은 표본 140편을 AI가 초록 의미로 분류했습니다. 사람 검증 또는 전편 본문 검증이 아닙니다. 표본에는 미상을 남기고 가중 추정과 보수적 95% 구간을 표시합니다. 전체 분야 점유율은 아니며 2026은 별도 부분 연도입니다. 분석 데이터와 짧은 근거
